# Blog

Design notes, debugging tours, and release retrospectives for the [tf-analyze](https://github.com/ChrisAdkin8/tf-analyze) project.

These posts are **versioned alongside the code** in [`docs/blog/`](https://github.com/ChrisAdkin8/tf-analyze/tree/main/docs/blog) — when an engine flag changes or a status-bar item moves, the post that documented it shows up in the same diff. If a post mentions a specific version (status bar layout, rule count, error message), trust the version pin in its frontmatter; later releases may have moved on.

## Posts

- **2026-05-09** — [Fourteen versions, six panels, one VSIX](2026-05-09-fourteen-versions-six-panels-one-vsix.html). The arc from v0.1.7 (a status-bar shortcut) to v0.1.22 (a self-contained `.vsix` with a real LSP server) — every bug we hit, why each "fix" exposed the next layer's bug, and what the dependency tree of failures actually looked like.
